# Modulo `m2`

> [!NOTE]
> Sorgente: [`lib/modules/m2.sh`](../../lib/modules/m2.sh). Il modulo gestisce l'avvio dinamico di Linux da SSD M.2 interno (NVMe) su PlayStation 5, integrando un hook nativo in `initrd.img` con fallback automatico e trasparente su memoria USB in caso di assenza dell'SSD.

## Obiettivo

1. **Rilevamento Dinamico & Boot Prioritario NVMe**: Se all'avvio della PS5 viene rilevata un'installazione Linux valida su SSD M.2 interno (`LABEL=cachyos-m2` o `/dev/nvme0n1p1`), l'early userspace indirizza il montaggio della rootfs su M.2 per beneficiare delle massime velocità di lettura/scrittura NVMe (fino a 5000-7000 MB/s).
2. **Fallback Automatico con Convalida Preventiva dell'Integrità OS**: Prima di commutare `root` sull'SSD interno, l'hook monta temporaneamente `nvme0n1p1` in sola lettura per verificare l'effettiva presenza di `/usr/lib/systemd/systemd` o `/sbin/init`. Se l'SSD M.2 non è presente, è vuoto o contiene un'installazione incompleta/corrotta, il sistema esegue un fallback trasparente sulla rootfs della chiavetta USB (`LABEL=cachyos`), prevenendo blocchi e kernel panic.
3. **Prevenzione Timeout APST NVMe**: Aggiunge il parametro `nvme_core.default_ps_max_latency_us=0` a `cmdline.txt`, disabilitando gli stati di transizione a risparmio energetico profondo (D3 latency) che causano timeout I/O su SSD Samsung 980/990 Pro nel bus PCIe Oberon della PS5.
4. **Override di Emergenza**: Se l'utente desidera forzare l'avvio da USB anche in presenza dell'SSD M.2 (es. per manutenzione o ripristino), è sufficiente passare il parametro `ps5.force_usb=1` nella riga di comando del kernel in `cmdline.txt`.
5. **Toolsuite di Gestione Integrata**: Installa su CachyOS gli strumenti `/usr/local/sbin/ps5-m2-migrate` e `/usr/local/sbin/ps5-m2-init` per consentire all'utente di inizializzare l'SSD con partizionamento compatibile LBA 65536, formattare in ext4 e clonare live il sistema operativo direttamente da console.

---

## Sequenza Operativa

1. **Ricezione e convalida mount**:
   Riceve i percorsi `$CACHY_MNT` e `$BOOT_MNT` dal master patcher.
2. **Backup di sicurezza preventivo**:
   Se non esiste già, crea una copia di sicurezza `$BOOT_MNT/initrd.img.bak`.
3. **Iniezione del hook nativo mkinitcpio**:
   - Individua l'offset di separazione tra il microcode AMD/firmware non compresso (early CPIO) e il ramdisk principale compresso con Zstandard.
   - Decomprime lo stadio zstd in un'area temporanea sicura.
   - Genera e installa lo script eseguibile `/hooks/ps5_m2_boot`.
   - Modifica `/config` aggiungendo `ps5_m2_boot` alla variabile `HOOKS` subito dopo `udev`.
   - Ricomprime con Zstandard (`zstd -10 -T0`) e ricombina con l'early CPIO, generando un'immagine atomica e deterministica.
4. **Allineamento `cmdline.txt`**:
   - Imposta come base `root=LABEL=cachyos` (se era presente `cachyos-m2` statico, lo normalizza in modo che il fallback USB rimanga sempre garantito).
   - Aggiunge `rootwait` per assicurare che il controller PCIe/NVMe ed i dispositivi USB abbiano il tempo necessario per completare l'enumerazione.
5. **Installazione Strumenti di Migrazione in CachyOS**:
   - Copia `bin/ps5-m2-migrate` in `${CACHY_MNT}/usr/local/sbin/ps5-m2-migrate` (`0755`).
   - Copia `resources/m2/ps5-m2-init` in `${CACHY_MNT}/usr/local/sbin/ps5-m2-init` (`0755`).
6. **Ottimizzazione `fstab`**:
   - Assicura che la partizione FAT32 USB (`/boot/efi`) sia montata con flag di sicurezza `flush,errors=remount-ro` su entrambe le configurazioni.

## File Modificati e Installati

| Percorso | Contenuto/effetto |

| `<BOOT_MNT>/initrd.img` | Ramdisk aggiornato con hook `ps5_m2_boot` e configurazione `HOOKS`. |
| `<BOOT_MNT>/initrd.img.bak` | Backup di sicurezza dell'immagine initrd originale. |

## Logica dell'Hook Runtime `/hooks/ps5_m2_boot`

```sh
#!/usr/bin/ash
run_hook() {
    # Override forzato da utente
    if [ "$(getarg ps5.force_usb)" = "1" ]; then
        msg ":: PS5 Boot: Rilevato parametro ps5.force_usb=1. Avvio forzato da chiavetta USB..."
        return 0
    fi

    # Attesa driver e blocco NVMe
    modprobe -q nvme 2>/dev/null || true
    udevadm settle --timeout=3 2>/dev/null || true

    local m2_dev=""
    for cand in "LABEL=cachyos-m2" "/dev/disk/by-label/cachyos-m2" "/dev/nvme0n1p1"; do
        if m2_dev="$(resolve_device "$cand" 2>/dev/null)" && [ -b "$m2_dev" ]; then
            break
        fi
        m2_dev=""
    done

    if [ -n "$m2_dev" ]; then
        msg ":: PS5 Boot: SSD M.2 interno rilevato ($m2_dev). Avvio prioritario da SSD M.2..."
        root="$m2_dev"
    else
        msg ":: PS5 Boot: Nessun SSD M.2 con Linux rilevato. Fallback automatico su chiavetta USB..."
        if [ "$root" = "LABEL=cachyos-m2" ] || [ -z "$root" ]; then
            root="LABEL=cachyos"
        fi
    fi
}
```

## Interfaccia del Modulo

- `module_m2_info()`: descrizione breve per `--list-modules`.
- `module_m2_run "$CACHY_MNT" "$BOOT_MNT"`: esegue l'iniezione del hook in `initrd.img`, l'allineamento di `cmdline.txt` e l'installazione dei binari in `usr/local/sbin`.
- `module_m2_check "$CACHY_MNT" "$BOOT_MNT"`: verifica la presenza dei file di migrazione e dell'hook.

## Comandi Utili per la Migrazione su PS5

Una volta avviata la console da chiavetta USB, l'utente può eseguire:

1. **Analisi preliminare**:
   ```bash
   sudo ps5-m2-migrate analyze
   ```
2. **Inizializzazione tabella partizioni a LBA 65536**:
   ```bash
   sudo ps5-m2-migrate init
   # Riavviare la console
   ```
3. **Formattazione e clonazione CachyOS su M.2**:
   ```bash
   sudo ps5-m2-migrate install
   ```
4. **Verifica stato**:
   ```bash
   sudo ps5-m2-migrate status
   ```

Fonte primaria: [`lib/modules/m2.sh`](../../lib/modules/m2.sh).
